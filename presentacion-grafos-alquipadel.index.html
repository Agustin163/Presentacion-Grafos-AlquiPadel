Recomendación de partidos abiertos con grafos ponderados

El problema

  • Un partido abierto necesita jugadores para completarse.
  • Hoy cada jugador revisa la lista completa y decide solo.
  • Un partido de otra categoría o en otra ciudad casi nunca se completa.

Objetivo

Mostrarle a cada jugador, primero, los partidos que mejor le calzan por categoría y localidad.

¿Por qué grafos?

  • Nodos: jugadores y partidos.
  • Aristas: compatibilidad entre un jugador y un partido.
  • Peso: número de 0 a 1 que mide esa compatibilidad.

Es un grafo bipartito ponderado: las aristas solo unen jugadores con partidos, nunca jugador con jugador.

Recomendar = ordenar las aristas de un jugador por peso.

Círculo blanco = jugador · círculo amarillo = partido abierto · número = peso. Cuanto más cerca de 1, mejor recomendación.

Los pesos 0.6 / 0.4 son ajustables (probalo en la demo). La categoría pesa más porque un partido desparejo no se disfruta.

Implementación: el grafo

Lista de adyacencia: el espacio crece con las aristas y recorrer vecinos es directo.


class GrafoPonderado {
  constructor() { this.adyacencia = new Map(); }

  agregarNodo(nodo) {
    if (!this.adyacencia.has(nodo)) this.adyacencia.set(nodo, []);
  }

  agregarArista(origen, destino, peso) {
    this.agregarNodo(origen);
    this.agregarNodo(destino);
    this.adyacencia.get(origen).push({ destino, peso });
  }

  vecinos(nodo) { return this.adyacencia.get(nodo) ?? []; }
}

Implementación: pesos y recomendación


const CATEGORIAS = ["8va","7ma","6ta","5ta","4ta","3ra","2da","1ra"];

function scoreCategoria(a, b) {
  const dif = Math.abs(CATEGORIAS.indexOf(a) - CATEGORIAS.indexOf(b));
  return dif === 0 ? 1 : dif === 1 ? 0.5 : 0;
}
function scoreLocalidad(a, b, vecinas) {
  if (a === b) return 1;
  return (vecinas[a] ?? []).includes(b) ? 0.5 : 0;
}
function calcularPeso(j, p, vecinas, wCat = 0.6, wLoc = 0.4) {
  return wCat * scoreCategoria(j.categoria, p.categoria)
       + wLoc * scoreLocalidad(j.localidad, p.localidad, vecinas);
}
function construirGrafo(jugadores, partidos, vecinas) {
  const g = new GrafoPonderado();
  for (const j of jugadores) for (const p of partidos) {
    const peso = calcularPeso(j, p, vecinas);
    if (peso > 0) g.agregarArista(j.id, p.id, peso);
  }
  return g;
}
function recomendar(g, idJugador, n = 3) {
  return [...g.vecinos(idJugador)].sort((a, b) => b.peso - a.peso).slice(0, n);
}

Complejidad

OperaciónCosto
Construir el grafo (J jugadores, P partidos)O(J × P)
Agregar una aristaO(1)
Recomendar (k aristas del jugador)O(k log k)
Espacio con lista de adyacenciaO(J + A)

Con matriz de adyacencia el espacio sería O(J × P), aunque casi todas las celdas valgan 0.

Posibles mejoras

  • Sumar criterios al peso: horario, historial y nivel de los otros jugadores.
  • Recorrer jugador → partido → jugador (BFS) para sugerir gente con quien ya jugaste.
  • Usar Dijkstra con costo = 1 − peso para buscar conexiones indirectas.
  • Evitar J × P: calcular solo contra partidos de la misma localidad y vecinas.

Conclusiones

  • Un grafo bipartito ponderado representa bien la relación jugador–partido.
  • El peso concentra todos los criterios en un solo número ajustable.
  • Recomendar se reduce a ordenar las aristas de un nodo.
